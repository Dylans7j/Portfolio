02 / FEATURED ENDPOINT INVESTIGATION

DE-003 — BadUSB & PowerShell

An evidence-led endpoint investigation connecting an encoded PowerShell process to its outbound network event.

DETECTION ENGINEERING / WINDOWS INCIDENT RESPONSE

BadUSB-initiated PowerShell execution and network callback

Process correlation verified

Investigated a controlled Flipper Zero BadUSB exercise against an isolated Windows 11 VM. A Kali listener captured an inbound session. Windows Sysmon recorded an encoded PowerShell process and its outbound TCP connection; Splunk linked process creation and network activity by the same ProcessGuid. PowerShell Script Block Logging recorded an attempted Defender configuration change—not verified successful disablement.

1 + 3Correlated Sysmon event IDs
4104PowerShell script block evidence
TCP 4444Lab callback port
1 GUIDMatched process-to-connection identity

Investigation outcomes

  • Correlated the suspicious Windows PowerShell process to its logged network connection using Sysmon ProcessGuid.
  • Identified normal Splunk PowerShell helper activity as background telemetry instead of labeling it malicious.
  • Separated observed execution and connection evidence from an unverified Defender impairment outcome.
  • Prepared a candidate SPL analytic and Sigma event rule; expanded detection and scheduled alert performance still require validation.
