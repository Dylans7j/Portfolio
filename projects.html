ENDPOINT TELEMETRY / SPLUNK

Windows 11 monitoring infrastructure

Validated in lab

Deployed Splunk Universal Forwarder on a VMware Windows 11 VM and connected it to the isolated Ubuntu Splunk Enterprise instance. Resolved a Sysmon event-channel permission failure by granting the forwarder service identity membership in Event Log Readers, then verified indexed telemetry in Splunk.

Observed evidence

  • Active forwarder connection confirmed and TCP connectivity tested from WIN11 to SPLUNK-01.
  • Indexed sources: Windows Security, System, PowerShell Operational and Sysmon Operational.
  • Sysmon Event ID 1 process creation confirmed locally; Sysmon source data subsequently observed in Splunk.
  • Indexer web interface reachable over the lab network. Event counts describe one search window, not ongoing ingestion volume.
